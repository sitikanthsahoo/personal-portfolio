# vCard Personal Portfolio

A modern, customizable personal portfolio website built with HTML, CSS, and JavaScript. Showcase your skills, projects, and contact information in a sleek, responsive design.

## Features

- Responsive layout for all devices
- Easy customization of content and styles
- Animated sections and smooth scrolling
- Project showcase with images and descriptions
- Downloadable resume/CV section
- Social media and contact links
- 
## Getting Started

1. **Clone the repository:**
    ```bash
    git clone https://github.com/yourusername/vcard-personal-portfolio.git
    ```
2. **Open `index.html` in your browser.**
3. **Customize content:**
    - Edit `index.html` for your info, projects, and contact details.
    - Update styles in `assets/css/` as needed.
    - Replace images in `assets/img/`.

## Customization

- Change colors and fonts in `assets/css/style.css`.
- Add or remove sections as needed.
- Update social links in the footer.

## Deployment

You can deploy your portfolio using GitHub Pages, Netlify, Vercel, or any static hosting provider.
